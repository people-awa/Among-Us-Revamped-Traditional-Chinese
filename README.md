# Among-Us-Revamped-Traditional-Chinese
- Among Us Revamped的繁體中文漢化

---

# 安裝教程

- 將下載好的AUR-Traditional-Chinese-1.8.2.dll 放入
```
└── 📁Among Us
     └── 📁BepInEx
          └── 📁plugins
               └── 📄AUR-Traditional-Chinese-1.8.2.dll
```
- 用於替換原Among Us Revamped的dll文件（我們未提供BepInEx本體文件，因爲這樣會超過25MB限制）。
- 安裝完成後即可啓動游戲後即可游玩。
